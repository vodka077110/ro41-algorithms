# СРСП 10. Сортировка пузырьком и подсчёт вхождений бинарным поиском

Код: [Program.cs](Program.cs)

## Методы `static class ArrayAlgos`

| Метод | Как работает |
|-------|--------------|
| `bool IsSorted(int[] a)` | проверяет, что `a[i] <= a[i + 1]` для всех соседних пар; пустой массив и массив из одного элемента — отсортированы |
| `int BubbleSort(int[] a)` | пузырёк на месте: соседние элементы сравниваются и меняются местами; после каждого прохода последний элемент уже на месте, поэтому внутренний цикл короче на 1. **Флажок `swapped`**: если за проход не было ни одного обмена — массив отсортирован, выходим досрочно. Возвращает число сравнений |
| `int CountOccurrences(int[] sortedA, int x)` | `UpperBound(x) − LowerBound(x)`: первый индекс элемента `> x` минус первый индекс элемента `>= x`. Два бинарных поиска, цикла по всему массиву нет |

`Array.Sort`, `Array.BinarySearch` и LINQ не используются.

### BubbleSort

| До | IsSorted до | После | IsSorted после | Сравнений |
|----|-------------|-------|----------------|-----------|
| {}              | True  | {}              | True | 0  |
| {5}             | True  | {5}             | True | 0  |
| {1, 2, 3, 4, 5} | True  | {1, 2, 3, 4, 5} | True | 4  |
| {5, 4, 3, 2, 1} | False | {1, 2, 3, 4, 5} | True | 10 |
| {3, 1, 3, 2, 3} | False | {1, 2, 3, 3, 3} | True | 9  |

- `{1, 2, 3, 4, 5}` — за первый проход 4 сравнения и ни одного обмена → ранний выход.
- `{5, 4, 3, 2, 1}` — худший случай: 4 + 3 + 2 + 1 = 10 сравнений.
- `{3, 1, 3, 2, 3}` — проходы 4 + 3 + 2 = 9: на третьем проходе обменов уже нет, выход.
- Отсортированный массив из 1000 элементов: **999 сравнений** (один проход без обменов) — **OK**.

### CountOccurrences на `{1, 2, 2, 2, 5, 7}`

| x | LowerBound (≥ x) | UpperBound (> x) | Вхождений | Ожидается | Результат |

| 2 | 1 | 4 | 3 | 3 | OK |
| 1 | 0 | 1 | 1 | 1 | OK |
| 7 | 5 | 6 | 1 | 1 | OK |
| 3 | 4 | 4 | 0 | 0 | OK |
| 9 | 6 | 6 | 0 | 0 | OK |
