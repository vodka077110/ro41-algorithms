# СРСП 8. Класс TextTools: обработка текста

Код: [Program.cs](Program.cs)

## Методы `static class TextTools`

| Метод | Как работает |
|-------|--------------|
| `int CountWords(string s)` | `Split(' ', RemoveEmptyEntries)` — пустые «слова» от лишних пробелов отбрасываются; пустая строка / только пробелы → 0 |
| `bool IsPalindrome(string s)` | два указателя (`left`, `right`) идут навстречу, пробелы пропускаются, буквы сравниваются через `char.ToLower` |
| `string Initials(string fullName)` | первая буква каждого слова в верхнем регистре + точка, через пробел; собирается в `StringBuilder` |
| `string Repeat(string s, int n)` | `StringBuilder` с заранее заданной ёмкостью, `Append(s)` n раз; при `n <= 0` или пустой `s` → `""` |

Regex и LINQ не используются. Пустая строка и строка из пробелов обрабатываются без исключений (проверка `string.IsNullOrWhiteSpace` в начале методов).

`Repeat` строится через `StringBuilder`, потому что `s += ...` в цикле создавал бы новую строку на каждой итерации.

## Проверка

```
dotnet run
```

Программа для каждой строки выводит вход, ожидаемое значение, фактическое и OK/FAIL. Результат: **23 из 23 OK**.

| Вход | CountWords | IsPalindrome | Initials | Repeat(s, 2) |
|------|------------|--------------|----------|--------------|
| `""`                           | 0 | True  | `""` | `""` |
| `"   "`                        | 0 | True  | `""` | `"      "` |
| `" a  b "`                     | 2 | False | `"A. B."` | `" a  b  a  b "` |
| `"А роза упала на лапу Азора"` | 6 | True  | `"А. Р. У. Н. Л. А."` | строка два раза подряд |
| `"Ахметов Ерлан"`              | 2 | False | `"А. Е."` | `"Ахметов ЕрланАхметов Ерлан"` |

Дополнительно: `Initials("Ахметов Ерлан Серикұлы")` = `"А. Е. С."`, `Repeat("ab", 3)` = `"ababab"`, `Repeat("ab", 0)` = `""`.

Пустая строка и строка из пробелов считаются палиндромами: после удаления пробелов остаётся пустая строка, а она читается одинаково в обе стороны.
