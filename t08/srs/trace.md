# СРС 8. Трассировка методов string и StringBuilder

## 1. `s.Trim()`, затем `Split(';')`

Исходная строка: `s = "  Ахметов Ерлан;85 "` (два пробела в начале и один в конце), длина **19**.

**Шаг 1 — `Trim()`** удаляет пробелы в начале и в конце строки (пробел внутри, между фамилией и именем, остаётся):

| Строка                   | Длина |
|--------------------------|-------|
| `"  Ахметов Ерлан;85 "`  | 19    |
| `"Ахметов Ерлан;85"`     | 16    |

**Шаг 2 — `Split(';')`** разрезает строку по символу `;` и возвращает массив:

| Индекс | Содержимое        | Длина |
|--------|-------------------|-------|
| 0      | `"Ахметов Ерлан"` | 13    |
| 1      | `"85"`            | 2     |

`"Ахметов Ерлан"`: «Ахметов» (7) + пробел (1) + «Ерлан» (5) = 13. Сам символ `;` в элементы массива не попадает.

## 2. `int.TryParse` для `line = "Иванов Пётр;70;85;x"`

`line.Split(';')` → `{"Иванов Пётр", "70", "85", "x"}`

| Индекс | Часть           | Результат TryParse | Значение out |
|--------|-----------------|--------------------|--------------|
| 0      | `"Иванов Пётр"` | false              | 0            |
| 1      | `"70"`          | true               | 70           |
| 2      | `"85"`          | true               | 85           |
| 3      | `"x"`           | false              | 0            |

Если `TryParse` не смог превратить строку в число, он не выбрасывает ошибку, а возвращает `false` и записывает в `out` значение `0`.

Метод `TryParseScores` (элемент 0 — это ФИО, оценки начинаются с индекса 1):

```csharp
static bool TryParseScores(string line, out int[] scores)
{
    string[] parts = line.Split(';');
    scores = new int[parts.Length - 1];
    for (int i = 1; i < parts.Length; i++)
        if (!int.TryParse(parts[i], out scores[i - 1]))
            return false;
    return true;
}
```

| i | parts[i] | TryParse | scores        | Действие          |
|---|----------|----------|---------------|-------------------|
| 1 | `"70"`   | true     | {70, 0, 0}    | дальше            |
| 2 | `"85"`   | true     | {70, 85, 0}   | дальше            |
| 3 | `"x"`    | false    | {70, 85, 0}   | **return false**  |

**`TryParseScores` вернёт `false`**, потому что последняя часть `"x"` — не число. Строка считается некорректной целиком: достаточно одной неверной оценки, чтобы метод сообщил об ошибке. Программа при этом не падает (в отличие от `int.Parse`, который выбросил бы `FormatException`).

## 3. `s += i` против `sb.Append(i)`

```csharp
string s = "";
for (int i = 0; i < 4; i++)
    s += i;
```

Строки в C# **неизменяемые**: `s += i` не дописывает символ в старую строку, а создаёт **новую** строку и переставляет на неё переменную `s`. Старая строка становится мусором.

| Шаг | i | Было в s  | Создаётся новая строка | Строк создано всего |
|-----|---|-----------|------------------------|---------------------|
| 1   | 0 | `""`      | `"0"`                  | 1                   |
| 2   | 1 | `"0"`     | `"01"`                 | 2                   |
| 3   | 2 | `"01"`    | `"012"`                | 3                   |
| 4   | 3 | `"012"`   | `"0123"`               | 4                   |

**Создаётся 4 новых объекта string** (по одному на каждой итерации; пустая строка `""` — это литерал, она существовала заранее). Из них в конце нужна только одна — `"0123"`, остальные 3 становятся мусором.

```csharp
var sb = new StringBuilder();
for (int i = 0; i < 4; i++)
    sb.Append(i);
string result = sb.ToString();
```

| Шаг | i | Действие               | Содержимое буфера sb | Новых объектов |
|-----|---|------------------------|----------------------|----------------|
| 0   | — | `new StringBuilder()`  | `""`                 | 1 (сам sb)     |
| 1   | 0 | `sb.Append(0)`         | `"0"`                | 0              |
| 2   | 1 | `sb.Append(1)`         | `"01"`               | 0              |
| 3   | 2 | `sb.Append(2)`         | `"012"`              | 0              |
| 4   | 3 | `sb.Append(3)`         | `"0123"`             | 0              |
| 5   | — | `sb.ToString()`        | —                    | 1 (строка `"0123"`) |

**При `sb.Append(i)` новых объектов не создаётся** — символы дописываются в уже существующий внутренний буфер одного объекта `StringBuilder`. Всего создаётся 1 объект `StringBuilder` и 1 строка при вызове `ToString()`. Поэтому для склейки строк в цикле `StringBuilder` работает быстрее и экономит память.

## 4. Почему `s.ToUpper()` без присваивания не изменил `s`

```csharp
string s = "abc";
s.ToUpper();          // результат никуда не сохранён
Console.WriteLine(s); // abc
```

Строка `string` в C# **неизменяемая** (immutable). Ни один метод строки (`ToUpper`, `Trim`, `Replace` и т. д.) не меняет исходную строку — он создаёт и **возвращает новую**. Здесь новая строка `"ABC"` создаётся, но её никуда не записали, и она сразу теряется, а `s` по-прежнему указывает на старую `"abc"`.

Правильно — присвоить результат:

```csharp
s = s.ToUpper();      // теперь s = "ABC"
```
