# СРСП 5. Рекурсивные методы DigitSum и Pow

Код: [Program.cs](Program.cs)

## Методы `static class Rec`

| Метод | Базовый случай | Шаг рекурсии |
|-------|----------------|--------------|
| `int DigitSum(int n)` — сумма цифр неотрицательного числа | `n < 10` → `return n` (однозначное число) | `n % 10 + DigitSum(n / 10)` |
| `long Pow(int x, int n)` — x в степени n (n ≥ 0) | `n == 0` → `return 1` | `x * Pow(x, n - 1)` |

Циклы и `Math.Pow` не используются. В каждом шаге аргумент уменьшается (`n / 10` или `n - 1`), поэтому рекурсия всегда доходит до базового случая.

Пример: `DigitSum(12345) = 5 + DigitSum(1234) = 5 + 4 + DigitSum(123) = … = 5 + 4 + 3 + 2 + 1 = 15`.
