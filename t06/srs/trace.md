# СРС 6. Трассировка сдвига и разворота массива

Исходный массив: `a = {4, 1, 7, 3, 9}`, длина `n = 5`.

## 1. Циклический сдвиг влево на одну позицию

```csharp
int tmp = a[0];                 // сохраняем первый элемент в буфер
for (int i = 0; i < n - 1; i++)
    a[i] = a[i + 1];            // каждый элемент сдвигаем на место левее
a[n - 1] = tmp;                 // первый элемент ставим в конец
```

| Шаг | i | Действие            | Состояние массива   |
|-----|---|---------------------|---------------------|
| 0   | — | tmp = a[0] = 4      | {4, 1, 7, 3, 9}     |
| 1   | 0 | a[0] = a[1] = 1     | {1, 1, 7, 3, 9}     |
| 2   | 1 | a[1] = a[2] = 7     | {1, 7, 7, 3, 9}     |
| 3   | 2 | a[2] = a[3] = 3     | {1, 7, 3, 3, 9}     |
| 4   | 3 | a[3] = a[4] = 9     | {1, 7, 3, 9, 9}     |
| 5   | — | a[4] = tmp = 4      | {1, 7, 3, 9, **4**} |

**Результат:** `{1, 7, 3, 9, 4}` — все элементы сдвинулись на одну позицию влево, а первый (4) переехал в конец.

Буфер `tmp` нужен потому, что на шаге 1 значение `a[0] = 4` затирается. Если его не сохранить заранее, четвёрка потеряется.

## 2. Разворот массива на месте

Трассировка выполняется для исходного массива `{4, 1, 7, 3, 9}`.

```csharp
for (int i = 0; i < n / 2; i++)
{
    int t = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = t;
}
```

`n / 2 = 5 / 2 = 2` (целочисленное деление), значит `i` принимает значения 0 и 1.

| Шаг | i | n − 1 − i | Обмен             | Состояние массива |
|-----|---|-----------|-------------------|-------------------|
| 0   | — | —         | —                 | {4, 1, 7, 3, 9}   |
| 1   | 0 | 4         | a[0] ↔ a[4] (4 ↔ 9) | {9, 1, 7, 3, 4} |
| 2   | 1 | 3         | a[1] ↔ a[3] (1 ↔ 3) | {9, 3, 7, 1, 4} |
| —   | 2 | —         | 2 < 2 — нет, выход | {9, 3, 7, 1, 4}  |

**Результат:** `{9, 3, 7, 1, 4}`. Выполнено **2 обмена**. Средний элемент `a[2] = 7` остаётся на месте — его не с кем менять.

**Почему цикл идёт только до n / 2:** за один обмен на свои места встают сразу **два** элемента — один слева и один справа. Когда `i` доходит до середины, весь массив уже развёрнут. Если продолжить цикл до `n`, вторая половина обменов поменяет те же пары **обратно**, и массив вернётся к исходному виду `{4, 1, 7, 3, 9}`.

## 3. Ошибка в поиске минимума с `min = 0`

```csharp
int min = 0;                    // ошибка!
for (int i = 0; i < n; i++)
    if (a[i] < min) min = a[i];
```

**Массив, на котором алгоритм ошибается:** `{4, 1, 7, 3, 9}` (или любой массив, где все числа больше 0).

| i | a[i] | a[i] < min ? | min |
|---|------|--------------|-----|
| — | —    | —            | 0   |
| 0 | 4    | 4 < 0 — нет  | 0   |
| 1 | 1    | 1 < 0 — нет  | 0   |
| 2 | 7    | 7 < 0 — нет  | 0   |
| 3 | 3    | 3 < 0 — нет  | 0   |
| 4 | 9    | 9 < 0 — нет  | 0   |

Алгоритм вернёт `0`, хотя в массиве нуля нет, а настоящий минимум равен `1`. Начальное значение 0 оказалось меньше всех элементов, поэтому ни одно сравнение не сработало.

**Исправление:** начинать с первого элемента массива. Тогда `min` с самого начала — реальное число из массива:

```csharp
int min = a[0];
for (int i = 1; i < n; i++)
    if (a[i] < min) min = a[i];
```

| i | a[i] | a[i] < min ? | min |
|---|------|--------------|-----|
| — | —    | —            | 4   |
| 1 | 1    | 1 < 4 — да   | 1   |
| 2 | 7    | 7 < 1 — нет  | 1   |
| 3 | 3    | 3 < 1 — нет  | 1   |
| 4 | 9    | 9 < 1 — нет  | 1   |

**Результат:** `min = 1` — верно. (Другой допустимый вариант — `int min = int.MaxValue;`, но `a[0]` проще и работает для любых чисел.)
