# СРСП 6. Методы для работы с массивом

Код: [Program.cs](Program.cs)

## Методы `static class ArrayOps`

| Метод | Что делает |
|-------|------------|
| `int Sum(int[] a)` | складывает все элементы в переменную `sum`, начиная с 0 |
| `int IndexOfMin(int[] a)` | начинает с `minIndex = 0` (минимум берётся из массива, а не 0), сравнивает строго `<`, поэтому возвращает индекс **первого** минимума |
| `int CountGreater(int[] a, int x)` | считает элементы, строго большие `x` |
| `void Reverse(int[] a)` | меняет местами `a[i]` и `a[n - 1 - i]` для `i` от 0 до `n / 2` — массив разворачивается на месте |

LINQ, `Array.Reverse` и `Math.Min` не используются.

## Проверка

```
dotnet run
```

| Массив | Sum | IndexOfMin | CountGreater(x = 2) | После Reverse |
|--------|-----|------------|---------------------|---------------|
| {4, 1, 7, 3, 9} | 24  | 1 | 4 | {9, 3, 7, 1, 4} |
| {5}             | 5   | 0 | 1 | {5}             |
| {-2, -7, -4}    | -13 | 1 | 0 | {-4, -7, -2}    |
| {2, 2, 2}       | 6   | 0 | 0 | {2, 2, 2}       |

Пояснения:
- `{-2, -7, -4}` — все числа отрицательные. Если бы минимум начинался с 0, ответ был бы неверным; здесь он берётся из массива, поэтому найден `-7` (индекс 1).
- `{2, 2, 2}` — все элементы равны, первый минимальный имеет индекс 0. `CountGreater` = 0, потому что `2 > 2` — ложь.
- `{5}` — в массиве из одного элемента `n / 2 = 0`, цикл разворота не выполняется ни разу.
