# СРС 1. Свойства алгоритма: примеры нарушений

Пять инструкций из жизни колледжа — по одному примеру на каждое свойство алгоритма.

## 1. Дискретность

**Исходная формулировка:**
> Подготовься к экзамену по алгоритмизации.

**Нарушение:** дискретность. Алгоритм должен состоять из отдельных законченных шагов, которые выполняются по очереди. Здесь вся работа записана одним большим действием: непонятно, с чего начать, что делать дальше и когда шаг закончен.

**Исправленная формулировка:**
1. Возьми у старосты список вопросов к экзамену.
2. Отметь вопросы, по которым нет конспекта.
3. Перепиши недостающие конспекты у одногруппника.
4. Каждый день разбирай по 5 вопросов из списка.
5. После разбора каждого вопроса ответь на него вслух без конспекта.
6. За день до экзамена ещё раз повтори вопросы, на которые не смог ответить.

## 2. Понятность

**Исходная формулировка (для первокурсника, который ни разу не работал с Git):**
> Закоммить лабу, запушь в репу и кинь линк в класрум.

**Нарушение:** понятность. Алгоритм должен состоять только из команд, которые входят в систему команд исполнителя. Первокурсник не знает слов «закоммить», «запушь», «репа», поэтому выполнить инструкцию не сможет.

**Исправленная формулировка:**
1. Открой папку репозитория `ro41-algorithms` на компьютере.
2. Щёлкни по адресной строке папки, введи `powershell` и нажми Enter.
3. Введи команду `git add .` и нажми Enter — Git запомнит новые файлы.
4. Введи `git commit -m "Лабораторная 1"` и нажми Enter — изменения сохранятся.
5. Введи `git push` и нажми Enter — файлы загрузятся на GitHub.
6. Скопируй ссылку на репозиторий со страницы GitHub.
7. В Google Classroom открой задание, нажми «Добавить» → «Ссылка», вставь ссылку и нажми «Сдать».

## 3. Определённость

**Исходная формулировка:**
> Приходи на консультацию пораньше и принеси несколько листов бумаги.

**Нарушение:** определённость (детерминированность). Каждый шаг должен пониматься однозначно, без вариантов. «Пораньше» — это за 5 минут или за час? «Несколько листов» — это 2 или 20? Разные студенты выполнят инструкцию по-разному.

**Исправленная формулировка:**
> Приходи на консультацию в четверг к 13:50 в аудиторию 214 и принеси 3 чистых листа формата А4.

## 4. Результативность

**Исходная формулировка:**
> Переделывай курсовую работу, пока она не станет идеальной.

**Нарушение:** результативность (конечность). Алгоритм должен за конечное число шагов приводить к результату. «Идеальная» работа — недостижимое и неизмеримое условие, поэтому цикл переделок может не закончиться никогда.

**Исправленная формулировка:**
1. Проверь курсовую по чек-листу преподавателя (10 пунктов).
2. Исправь все пункты, которые не выполнены.
3. Отправь работу преподавателю на проверку.
4. Если преподаватель вернул работу с замечаниями — исправь их и отправь снова, но не позже срока сдачи.
5. Когда работа принята или наступил срок сдачи — закончи.

## 5. Массовость

**Исходная формулировка:**
> Чтобы узнать средний балл, сложи 4, 5 и 3 и раздели сумму на 3.

**Нарушение:** массовость. Алгоритм должен решать целый класс однотипных задач, то есть работать для разных исходных данных. Эта инструкция подходит только одному студенту с оценками 4, 5 и 3; для другого набора оценок она даст неверный ответ.

**Исправленная формулировка:**
1. Выпиши все свои оценки по предмету из электронного журнала.
2. Посчитай количество оценок `k`.
3. Сложи все оценки — получишь сумму `S`.
4. Раздели `S` на `k` — это и есть средний балл.
